```

   ↓
TASK-02 generate placeholder hero (OpenAI gpt-image-1 + sharp variants)
   ↓
TASK-03 generate OG cards (welcome-uk.png + welcome-pt.png)
   ↓
```

## Token budget

Total est. ≈ 55k. Realistic given the explicit content (English-language file
edits — Ukrainian + Portuguese copy strings live inside JSX, not separate
content files).

## Out of scope (explicitly punted to other features)

- Replace placeholder mascot with canonical brand mascot →
  `print-stickers-posters`.
- Site-wide Plausible rollout → separate analytics SDD.
- Restructuring root site under `/uk/` → bigger SEO + redirect feature.
- 404 → Telegram alerting → existing pipeline notification SDD.
- Per-sticker UTM token in TG `?start=` → analytics follow-up.

## Rollback

Single revert. All changes are additive — new files, no modifications to
`pipeline/`, no `gatsby-node.js` change, no `gatsby-config.js` plugin
addition. `git revert <merge-or-range>` removes the welcome pages cleanly.
