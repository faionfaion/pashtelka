# TASK-05 — Content directory migration script + run

**Subject:** Migrate every `content/<slug>.md` to
`content/<slug>/uk.md` via `git mv`. The migration is idempotent and
content-preserving (no body text changes).

## Files touched

- `scripts/migrate_to_locale_dirs.py` (new)
- 158 file renames in `content/` (one git commit, generated by the
  script)

## Approach

```python
def main(dry_run: bool, root: Path) -> None:
    moved = skipped = 0
    for md in sorted(root.glob("*.md")):
        slug = md.stem
        target_dir = root / slug
        target = target_dir / "uk.md"
        if target.exists():
            skipped += 1
            continue
        if dry_run:
            print(f"would mv {md.name} -> {slug}/uk.md")
            continue
        target_dir.mkdir(parents=True, exist_ok=True)
        _git_mv(md, target)
        moved += 1
    print(f"moved={moved} skipped={skipped}")
```

`_git_mv` runs `git mv src dst`. Falls back to `shutil.move` if not in a
git repo (operator running on a checkout copy).

Idempotency: re-running matches no `*.md` directly under `content/` (they
are now nested inside `content/<slug>/`), so the loop body is empty.

After running the script:

```bash
git add -A   # no-op since git mv staged everything
git status   # see 158 renames
git commit -m "chore: migrate content/ to per-slug locale dirs"
```

We commit the renames in **one** commit. No body content changes
(verified by `git diff --stat HEAD~1 HEAD` showing only renames).

## Success criterion

- `python3 scripts/migrate_to_locale_dirs.py --dry-run` lists ~158 moves.
- After running, `ls content/` shows directories, no `.md` files at top
  level.
- `ls content/<some-slug>/` shows `uk.md`.
- Re-run prints `moved=0 skipped=158`.
- Commit shows ~158 renames, zero body changes.

## Rollback

`git revert <migration commit>` reverses the renames. Or operator
manually moves files back:

```bash
for d in content/*/; do
  mv "$d/uk.md" "${d%/}.md" && rmdir "$d"
done
```
